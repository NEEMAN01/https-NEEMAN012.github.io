# Gallery file naming

New gallery photos are discovered automatically. No HTML page edit is required.

## Recommended file name

`YYYY-MM-topic-category-01.jpg`

Examples:

- `2026-09-help-repatriants-01.jpg`
- `2026-09-canteen-meal-01.jpg`
- `2026-09-holocaust-support-01.jpg`
- `2026-09-college-meeting-01.jpg`
- `2026-09-sukkot-holidays-01.jpg`
- `2026-09-community-friends-01.jpg`

Use `YYYY-MM-DD-...` when the exact day is important.

## Folders

- `repatriants/`
- `canteen/`
- `holocaust/`
- `college/`
- `holidays/`
- `friends/`

The website reads image files in these folders automatically. Date-prefixed photos are shown before older undated files.

Files containing `overview`, `gallery` or `main` are treated as legacy/fallback collages when no individual photos are available.

    var bDate = parseDateFromName(b.name || b.path || "");

      var ak = aDate.year * 10000 + aDate.month * 100 + (aDate.day || 0);
      var bk = bDate.year * 10000 + bDate.month * 100 + (bDate.day || 0);
      if (ak !== bk) return bk - ak;
    } else if (aDate) {
      return -1;
    } else if (bDate) {
      return 1;
    }

    var da = a.added || "";
    var db = b.added || "";
    if (da !== db) return db.localeCompare(da);
    return (b.name || "").localeCompare(a.name || "");
